# 新增文章

1. 在本目录新增一个 `.md` 正文文件。
2. 把封面和正文图片放入 `public/articles/`。
3. 图片使用 `/articles/文件名` 引用，并填写准确的替代文本。
4. 在 `src/data/articles.js` 增加索引，填写全部字段。
5. `slug` 只用小写字母、数字和连字符，且不得重复。
6. 按发布日期从新到旧排列索引。
7. 正文至少包含 500 个中文字符、二级标题、列表、代码块和链接。
8. 运行 `npm test`、`npm run lint`、`npm run build`。

这里的两篇文章均为可替换示例，发布前可按相同步骤替换。
