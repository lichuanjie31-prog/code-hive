# 校园竞赛资讯专区（第一版资料，第二版 API 接入）

访问 `#/competitions`；详情地址用 slug，数据库或互动关联应使用稳定的 `competition.id`。比赛、赛道和节点 ID 不随显示名称改变。

## 维护边界

- `backend/seed/competitions-v1.json`：不可变的首版迁移快照，保留当时的事实、年份、来源与分析；不作为前端运行时数据源。
- 后端数据库的 `competitions`、`tracks`、`sources`、`milestones`：第二版唯一运行时比赛数据源。资料更新由后端维护，并用新迁移或受控后台数据流程执行；不要修改已执行的快照迁移。
- `src/competitions/competition-repository.js`：通过 API 加载数据，保留纯筛选、路由与时间轴工具，页面不导入事实快照。
- `src/competitions/CompetitionsPage.jsx`：列表与详情；独立反馈组件和样式。
- 第二版收藏与订阅以稳定比赛 ID 关联；点赞、推荐和自动通知不在本版范围。

## 资料核验（2026-10-04）

所有资料适用 2026 届，并非下一届报名通知。详情页有逐项来源及核验说明。

- 软件杯：官网访问超时，采用辽宁工程技术大学转载的当届组委会通知核实资格、A/B 组及作品要求。3 月原始计划与汝州职业技术学院 6 月后续通知日期不同，最终日期待确认，不能据此宣传正在报名。技术方向是本站标签，A/B 组只是第一版整理的官方分组；专项赛题及实际决赛日程待补。
- 服创赛：当届组委会举办通知核实 A/B/C/D 类与资格；使用 3 月 17 日延期文件和 4 月提交指南，不沿用早期未延期日程。区域赛与全国决赛具体日期尚未全部核实。
- 计算机设计大赛：已确认正式名称；使用官网第十九届预通知、4 月材料模板通知及软件开发国赛落幕公告。首版选择 4 个开发方向，并非全部 11 大类。官网附件材料的详细清单、人数和子类尚未完全核实，显示待确认。
- 学校未指定，校内日程不使用其他学校日期；省赛依各赛区安排。仅有日期的通知不补具体时刻。
- 下一届资料待公布，不按年份推断届次、日期或报名地址。

## 反馈

默认无接收渠道，页面明确告知无法在线提交，不提供模拟成功反馈。设置 `.env.local` 的 `VITE_COMPETITION_FEEDBACK_EMAIL` 为真实本站公开接收邮箱后，重启开发服务器；生产构建则需重新构建。组件打开邮件客户端草稿，实际发送由用户在邮件客户端完成，无后端保存。

## 本地预览和检查

```sh
npm run dev -- --host 127.0.0.1
# 访问终端输出的地址 + /#/competitions
npm run build
npm run lint
npm test
```

第二版浏览比赛需同时启动后端，步骤见 [第二版开发与接口约定](member-access-v2.md)。

构建需先于测试（现有文章测试会检查生产制品）。本地管理员功能仍只在开发环境开放。没有推送或部署步骤。

可选浏览器检查无需额外 npm 依赖，使用本机 Edge 的临时独立 profile：

```sh
node scripts/verify-competition-ui.mjs
```

先启动开发服务器。非 Windows 环境可用 `COMPETITION_TEST_BROWSER` 指定 Chromium 路径；端口变化可用 `COMPETITION_TEST_URL` 指定预览地址。脚本覆盖桌面与手机宽度、搜索重置、方向筛选、赛道时间轴、错误路由、无反馈配置、首页锚点及文章回归，截图默认写入系统临时目录。
